# DWT (Data Watchpoint and Trace) Library

Библиотека для измерения времени выполнения кода на микроконтроллерах STM32 с использованием DWT счетчика тактов.

## Подключение к проекту

Добавьте в ваш `CMakeLists.txt`:

```cmake
add_subdirectory(dwt)  # For DWT library
target_link_libraries(${CMAKE_PROJECT_NAME} dwt)
```

## Примеры использования

### Пример 1: Прямое использование регистра DWT_CYCCNT

```c
uint32_t count_tic = 0;

dwtInit();
DWT_CYCCNT = 0;  // обнуляем счётчик

// здесь кусок измеряемого участка программы

count_tic = DWT_CYCCNT;  // кол-во тактов
```

### Пример 2: Использование функций-обёрток

```c
uint32_t count_tic = 0;

dwtInit();
dwtRest();  // обнуляем счётчик

// здесь кусок измеряемого участка программы

count_tic = dwtGet();  // кол-во тактов
```

## Описание функций

- `dwtInit()` - инициализация DWT модуля
- `dwtRest()` - сброс счетчика тактов в ноль
- `dwtGet()` - получение текущего значения счетчика тактов
- `DWT_CYCCNT` - прямой доступ к регистру счетчика тактов

## Примечания

- DWT доступен только на процессорах Cortex-M3/M4/M7
- Счетчик считает такты ядра процессора
- Для получения времени в секундах разделите результат на частоту системного тактирования
